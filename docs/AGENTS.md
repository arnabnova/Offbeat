# Rules for the agent
- Read docs/PRD.md before starting any task.
- Use Next.js (App Router), TypeScript and Tailwind only. No Python, no Streamlit.
- Never hardcode places, hotels, restaurants or tips. All of it comes from live APIs.
- Call external APIs from server code only.
- Keep keys in .env.local. Never print them or commit them.
- Keep each change small and list the files you changed.
- If something is unclear, ask before guessing.
